# Przegląd zmian 0.0.11–0.0.17 w świeżym kontekście (2026-10-10)

Przegląd wg ADR 0016 (osobna sesja, odczyt kodu, bez uruchamiania). Zakres: strojenie mowy, miernik poziomu mowy,
kilka kart graficznych, belka okna, ekran ładowania, „opisz mi to, co widzisz”, import kluczy ze zmiennych.
Moduł kamer ma osobny przegląd: [`2026-10-10-przeglad-kamer.md`](2026-10-10-przeglad-kamer.md).

## Ustalenia

| ID   | Waga               | Ustalenie                                                                                                                                                                | Stan                                                                                                                                                                                                               |
| ---- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Z-01 | ważne (prywatność) | „Opisz, co widzisz” działało także przy zwykłych zdaniach: „Co widzisz w tym kodzie?”, „What do you see wrong in this code?” — przy włączonych kamerach robiłoby zdjęcie | **naprawione** — prośba musi być całą wiadomością („opisz mi to, co widzisz”) albo zawierać słowo „kamera”; testy przypadków negatywnych                                                                           |
| Z-02 | ważne (prywatność) | Zdjęcie było dołączane i wysyłane w jednym kroku — użytkownik nie widział go przed wysłaniem                                                                             | **naprawione** — pierwszy Enter tylko dołącza zdjęcie (widać je przy polu, jest komunikat), drugi wysyła; zdjęcie można usunąć                                                                                     |
| Z-03 | ważne              | Ekran ładowania mógł zostać na zawsze (błąd przed uruchomieniem interfejsu, rdzeń nie odpowiada) i zasłaniał przyciski okna                                              | **naprawione** — błąd startu jest pokazywany na ekranie ładowania z przyciskiem „Zamknij program”; po 20 s to samo wyjście; górny pas ekranu przesuwa okno                                                         |
| Z-04 | drobne             | Pamięć fraz mowy nie uwzględnia strojenia (tempo, głośność, pauza)                                                                                                       | **otwarte** — pamięć fraz nie jest dziś podłączona w programie; do zrobienia przed jej włączeniem (klucz z odciskiem strojenia)                                                                                    |
| Z-05 | ważne              | Wykrywanie kart przez `llama-server --list-devices` blokowało wątek do 8 s z zamkiem w ręku, a pusty wynik zostawał w pamięci do restartu                                | **częściowo naprawione** — zamek nie jest trzymany na czas sondy, pusty wynik nie jest zapamiętywany; sonda nadal działa synchronicznie przy pierwszym uruchomieniu modelu (do przeniesienia na zadanie blokujące) |

Uwagi poniżej progu pewności, zapisane do sprawdzenia: przy ścieżce bez pliku silnika dzierżawa pamięci modelu może
nie zostać zwolniona (`placement.rs`, możliwe że starsze niż 0.0.11); przerwany import kluczy nie ogłasza kont
dodanych przed błędem; wiadomość sterująca pracującą agentką staje się nową turą, gdy jest do niej dołączony plik.

## Sprawdzone i poprawne (wg przeglądu)

- Parametry Pipera: `--length_scale` = 1 / tempo (większa wartość = wolniej), zakresy ograniczone, limit czasu procesu.
- Znaczniki słów i czasy fragmentów po zmianie tempa i dodaniu pauzy są spójne; nic w potoku głosowym nie zakłada,
  że długość dźwięku równa się długości mowy.
- Obserwacja ustawień mowy: brak albo zła wartość daje ustawienia zalecane.
- Miernik poziomu mowy: jedno zadanie na zdanie, zatrzymanie unieważnia zaplanowane pomiary.
- Router: nieskonfigurowany dostawca „lekki” przepuszcza zadanie do następnego.
- Belka okna: przyciski nie są regionami przeciągania; uprawnienia okna są minimalne; zamknięcie nadal chowa do
  zasobnika; nasłuch zmiany rozmiaru jest sprzątany.
- Import kluczy: raport zawiera tylko nazwy zmiennych; wartości nie trafiają do logów.
