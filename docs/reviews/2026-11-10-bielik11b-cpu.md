## Odczytany wynik

- Model załadował się po **53722ms**.
- Pierwsze HTTP200, połączenie miało komentarze SSE mniej więcej co10s, lecz **zero tekstu**.
- Po **120014ms od wysłania HTTP** wystąpił timeout. **0 odpowiedzi,1 błąd,2 niewykonane**.
- Jakość semantyczna: **NOT_EVALUATED**. Kontroler zakończył się kodem0, bo zapisał dane;
  nie oznacza to zaliczonej próby. Nie ponawiano żądania dla zielonego wyniku.
- Zamknięto wyłącznie własny serwer; po SIGTERM potrzebny był SIGKILL, kod procesu -9.
  Czas utworzenia, grupa i PID pozostają w statusie. Inne zadania nie były zatrzymywane.

To surowy HTTP poza Core/LocalProvider, bez nowego aplikacyjnego limitu treści.
Komentarze transportu nie są TTFT. Nie łączymy czasu od startu serwera, HTTP i tury UI.
Surowy kolektor nie utrwalał finish_reason/usage; ponieważ nie ma odpowiedzi, nie ogłaszamy
żadnego zaliczenia semantyki lub braku ucięcia.

Potrzebny jest pomiar na docelowym RTX2060 **12GB**: zimny/ciepły start,8k kontekstu,
zapas VRAM obok mowy i ekranu oraz później rzeczywista jakość wszystkich person.
Obecny katalog deklaruje11B jako alternatywę tekstową **bez potwierdzonego tool calling**;
nie kwalifikuje tej próby jako odbioru kodowania lub sterowania komputerem.
