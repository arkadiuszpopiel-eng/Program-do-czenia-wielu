Decyzje (ADR)

  • Rejestr decyzji architektonicznych (ADR)
  • ADR 0001 — Stos: Rust + Tauri 2 + Svelte 5
  • ADR 0002 — Mikrojądro i format modułu (trójka crate'ów, manifest)
  • ADR 0003 — Izolacja Brokera i Broker-UI na wyższym poziomie integralności
  • ADR 0004 — ML runtime bez Pythona (whisper.cpp Vulkan/CUDA, ONNX Runtime CPU, sherpa-onnx)
  • ADR 0005 — Dwa kontrakty: ModelProvider (tokeny) i AgentBackend (zadania)
  • ADR 0006 — Historia rozmowy append-only + gałęzie
  • ADR 0007 — Instalacja: stały launcher, wersje side-by-side, stały folder WebView2
  • ADR 0008 — Dane: SQLite (WAL) szyfrowane + sqlite-vec + FTS5 w jednej bazie per sesja
  • ADR 0009 — Markdown z LLM renderowany w Rust; sandboxowany iframe tylko dla artefaktów HTML/SVG
  • ADR 0010 — Reguła skrótów globalnych (polski AltGr) i kill-switch Ctrl+Shift+F12
  • ADR 0011 — Silniki głosu v0 i audio: crate wasapi, AEC z własną referencją TTS
  • ADR 0012 — Wtyczki AI: wasmtime + własny WIT (cel wasip2), bez importów WASI
  • ADR 0013 — Kontrakty i generowanie typów: Rust → TS (tauri-specta/ts-rs), JSON Schema zdarzeń, WIT
  • ADR 0014 — Lokalny LLM: wbudowany llama.cpp (Vulkan/CUDA/CPU) zamiast Ollamy
  • ADR 0015 — Model uprawnień: tokeny zdolności i poziomy autonomii L0–L4
  • ADR 0016 — Jeden wykonawca (Claude Code); recenzja w świeżym kontekście zamiast drugiego modelu
  • ADR 0017 — Strategia wieloplatformowa: Windows 11 pierwszy, potem panel WWW, Android 15+ i Linux
  • ADR 0018 — Fabryka platform (platform-select) i kontrakty Brokera niezależne od systemu
  • ADR 0019 — Protokół klient–host niezależny od transportu
  • ADR 0020 — Host bez okna: binarka alfa-host, okno Tauri jako klient lokalny
  • ADR 0021 — Dostęp zdalny: przekaźnik, kanał end-to-end i parowanie urządzeń
  • ADR 0022 — Zgody zdalne: dowód urządzenia sparowanego (PairedDevice)
  • ADR 0023 — Tryb bez komputera: klucz API na urządzeniu i scalanie rozmów
  • ADR 0024 — Licencja silnika mowy (następca Pipera na GPL-3.0)
  • ADR 0025 — Kamery i biometria twarzy: zgoda, dane tylko lokalnie, rozpoznanie nie jest autoryzacją
  • ADR 0026 — Głos agentek z chmury jako opcja obok głosu lokalnego
  • ADR 0027 — Wielu użytkowników: konta, logowanie i role
  • ADR 0028 — DirectML dla głosu Supertonic i rozpoznawanie mowy na kartach AMD/Intel
  • ADR 0029 — Konta dzieci: wiek, podgląd rodzica, chmura, odznaki
