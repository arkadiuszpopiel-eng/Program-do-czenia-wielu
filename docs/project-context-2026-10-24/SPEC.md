# Kontekst projektu w żądaniu modelu

Ogólna prośba o analizę programu w rozmowie przypisanej do projektu odnosi się do projektu i aktywnego katalogu wybranego przez właściciela. Pierwsze żądanie Dyrygentki i żądania wykonawczyń muszą zawierać te metadane, bez czytania całego dysku. Zawartość plików wymaga rzeczywistego odczytu narzędziami. Zmiana projektu odświeża kontekst nowego żądania; wyłączony katalog nie zostaje odblokowany. Wznowione wykonanie zachowuje swój pierwotny zapis i zakres. Nazwy i ścieżki są danymi JSON, nie instrukcjami. Jawne wskazanie innego celu w poleceniu ma pierwszeństwo. Analiza i zalecenia nie oznaczają zgody na edycję.

Regresja: faktyczny HTTP z pełnym rdzeniem i Routerem, przypisany projekt, README w jego katalogu. Sprawdzić nazwę i ścieżkę w żądaniu Alfy i Delty oraz rzeczywisty wynik odczytu katalogu. Dodatkowo zmiana projektu, wyłączenie katalogu i bezpośrednia Delta.
