# tools-input-contract

tools-input: kontrakt narzędzi wejścia syntetycznego agentek — tekst Unicode, skróty, kliknięcia, przewijanie; nigdy do okien Alfy/Brokera, przerwanie przy fizycznym wejściu użytkownika, limit tempa.

Kontrakt modułu `tools-input`: trait, typy, zdarzenia i współdzielone testy kontraktowe. Inne moduły zależą wyłącznie od tego crate'a.

Specyfikacja: [`docs/modules/tools-input/SPEC.md`](../../docs/modules/tools-input/SPEC.md).

cargo test -p tools-input-contract
