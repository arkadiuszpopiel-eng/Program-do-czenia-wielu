# tools-shell-contract

tools-shell: kontrakt narzędzia powłoki — argumenty i wynik (JSON Schema), manifesty, heurystyki polecenia (destrukcja, instalacja, egress z hostami, ścieżki), konfiguracja powłok.

Kontrakt modułu `tools-shell`: trait, typy, zdarzenia i współdzielone testy kontraktowe. Inne moduły zależą wyłącznie od tego crate'a.

Specyfikacja: [`docs/modules/tools-shell/SPEC.md`](../../docs/modules/tools-shell/SPEC.md).

```bash
cargo test -p tools-shell-contract
```
