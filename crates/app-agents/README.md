# app-agents

Agentki z narzędziami w aplikacji (kategoria app-*): zestawy tools-fs/shell/clipboard (F6: także office/browser/system/net) przez Brokera i dziennik cofania, specyfikacja przebiegu agent-runtime z obsady i budżetów, projekcja zdarzeń agent.* na Replay i karty UI, zestaw ewaluacyjny narzędzi F3.

Warstwa kompozycji aplikacji (`app-*`): składa moduły w całość dla `app-core` i powłoki; nie jest modułem z trójką `contract/impl/fake`.

```bash
cargo test -p app-agents
```
